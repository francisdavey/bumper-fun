This post exists to prove the two layout patterns survive contact with
Jekyll, not just a standalone HTML file. Below, a short derivation using
the centred equation pattern, with asides flushed to the right.

<div class="eq-grid" markdown="0">
  <div class="eq-row">
    <div class="eq-lhs">\(x\)</div>
    <div class="eq-rhs">\({}= y + z\)</div>
    <div class="eq-note">definition of \(x\)</div>
  </div>
  <div class="eq-row">
    <div class="eq-lhs"></div>
    <div class="eq-rhs">\({}= a + b + z\)</div>
    <div class="eq-note">substituting \(y = a + b\)</div>
  </div>
</div>

## The same thing, without typing HTML

The block above is what the layout actually needs, but you don't have
to type it by hand. `_includes/mathformat.html` does the same job from
one line per equation row — `lhs || rhs || note` — expanded into the
grid above by Liquid at build time, no JavaScript involved:

```liquid
{% include mathformat.html rows="x || = y + z || definition of x
|| = a + b + z || substituting y" %}
```

{% include mathformat.html rows="x || = y + z || definition of x
|| = a + b + z || substituting y" %}

That's the identical result as the hand-written block above it —
compare the two if you like. From here on, use the include; the
hand-written version above is only in this post to show what it's
doing under the hood.

And here's the margin-note pattern in ordinary prose, which mixes fine
with normal markdown since it's just inline HTML in a paragraph.

<p class="with-note">
A claim that wants a small qualification without derailing the sentence.
<span class="sidenote">An aside that belongs beside the text, not inside it.</span>
The paragraph carries on underneath regardless of how long the note runs.
</p>

## One gotcha worth knowing now

Jekyll's markdown processor (kramdown) will try to parse ordinary
markdown syntax — `_underscore_`, `*asterisk*`, backslashes — even
inside blocks of raw HTML, which collides with LaTeX syntax (`x_1`,
`a^2`, `\frac{}{}`). The fix is the `markdown="0"` attribute on the
outer `<div>`, as used above: it tells kramdown "leave this block
alone, verbatim." Use it on any block-level HTML you paste in that
contains maths. Note also `\(...\)` is used here instead of `$...$`
— dollar signs are fine too, but backslash-parens sidestep any future
clash with markdown's own use of `$` in some configurations.
